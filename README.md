# Mozamoza

Mozamozaは、画面共有や収録で見せたくない情報を、複数のマスクで隠せるmacOSアプリです。元のアプリはそのまま操作しながら、選んだウィンドウとマスクを一枚に合成した専用の共有ウィンドウをZoom、Google Meet、Teams、OBSなどへ渡せます。

## ダウンロード

公開版は現在準備中です。初回リリース後は、このリポジトリの[Releases](https://github.com/Tackrow/Mozamoza/releases/latest)からApple公証済みのDMGをダウンロードできます。

## 動作環境

- macOS 14以降
- Apple SiliconまたはIntel Mac
- 共有ウィンドウと画面上のマスクには、macOSの「画面収録」許可が必要です

## アップデート

公開版はアプリ内からアップデートを確認できます。更新ファイルはインストール前に署名を検証し、自動確認の有効・無効はMozamozaの設定から変更できます。

## プライバシー

画面映像とマスク処理はMac内で完結します。Mozamozaが映像を保存したり、外部サーバーへ送信したりすることはありません。

## このリポジトリについて

ここはMozamozaの配布専用リポジトリです。`main`ブランチには案内用READMEだけを置き、Apple公証済みのアプリはGitHub Releasesの資産として配布します。ソースコードは非公開の別リポジトリで管理しています。
